# ShiftED acronym and terminology key

From weekly meeting 27 May 2026 — keep in sync with `skills/skillsLibrary.cjs`. Expanded with ShiftedAI Resources (2026-10).

| Term | Meaning |
|------|---------|
| **BA** | Behavioural Activation (Development/Activation skill) |
| **HCPR** | Helpful, Constructive, Positive, Real — thought-challenging toolkit |
| **DTR** | Daily Thought Record / “thought on trial” |
| **ABCD** | Activating event, Beliefs, Consequences, Disputation |
| **SOBER** | Stop, Observe, Breath, Expand, Respond — stress interruption |
| **WoT** | Window of Tolerance — usable arousal range for learning |
| **SPS** | Structured Problem Solving |
| **Core Skills** | Engine skills used with conceptualisation (distancing, grounding, thought tools, problem-list) |
| **Development/Activation Skills** | Phase 2–3 modules (BA, micro goals, values, strengths, sustainability path, etc.) |
| **Phase 1** | Person-centred conceptualisation |
| **Phase 2** | Goal setting |
| **Phase 3** | Skill application |
| **Distancing** | Core skill — create distance from stress response |
| **Micro goals** | Small observable steps (plain language; avoid “SUDS” with users) |
| **KB** | Knowledge base — atomic retrieval docs under `knowledge-base/` |

**Note:** Prefer “Behavioural Activation” or “micro goals” over “Subjective Units of Distress (SUDS)” in user-facing AI text.
